# 益护夕阳 · 演示原型

适老化普法与维权服务框架，供团队评审。

## 演示范围

首页、学法与问法、一键维权、我的；支持线索分步记录、本机附件保存、内容搜索、大字版与家人协助。

所有法律内容均为待审核的示例，不构成法律意见；没有真实机构受理、AI 咨询或案件办理。请使用虚构信息体验。

## 数据

线索和附件只存储在各自浏览器中，不上传到 GitHub，不跨设备同步。清除浏览器网站数据会删除记录。

## 本地预览

在仓库目录执行 `python -m http.server 4173 --directory dist`，访问 `http://localhost:4173`。

## 维护与发布

- `dist/content.js`：文章、案例和问答模板。
- `dist/app.js`：交互与本机存储。
- `dist/styles.css`：响应式界面。
- `.github/workflows/pages.yml`：仅发布 `dist` 的 GitHub Pages 工作流。

本仓库仅包含新建原型文件，不包含原始项目书、调研材料或用户记录。

## V0.2 更新

- 大字版正文 24–26px，辅助文字 20px。
- 默认舒缓 0.78 倍朗读，支持设备普通话音色选择、试听和语速设置；实际音色由设备与浏览器提供，未接入独立云端 TTS。
- 首页 12315 / 12348 热线入口，点击后打开用途说明与拨号按钮。
- 夕阳树洞支持匿名本机发帖、评论、分类与删除；虚构示例明确标记，未对其他用户公开。
- 新增 `dist/features.js`，存储仍为浏览器本机数据，没有远程社区后台。
