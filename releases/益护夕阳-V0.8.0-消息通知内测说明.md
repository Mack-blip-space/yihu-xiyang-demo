# 益护夕阳 V0.8.0：消息通知内测

本版在现有家庭守护圈和人工咨询工单上增加安卓锁屏通知。通知仅作到达提醒，不代表机构受理，也不能替代电话求助。

## 通知范围

- 长辈发送家庭求助后，提醒已绑定的家人。
- 志愿者回复人工咨询后，提醒原提交设备。
- 用户补充咨询后，提醒接单志愿者；尚未接单时提醒已订阅的内测工作台设备。

锁屏只显示“新的家庭守护消息”“人工咨询有新回复”等概括文字，不显示咨询问题、回复正文、姓名、电话、定位、附件或其他案件内容。点击通知后进入对应页面查看。

## 开启和关闭

在安卓体验版进入“我的 → 消息通知”。用户主动点击“开启通知”后，系统才会申请通知权限并登记设备。页面支持重新同步、暂停 8 小时和关闭。网页版保留全部业务功能，但不申请浏览器推送权限。

通知可能受断网、系统省电、权限关闭和 Firebase 服务状态影响，不能保证即时送达。家庭急事应直接拨打家人电话，紧急危险应拨打 110。

## 数据边界

通知服务只保存随机安装标识、不可逆身份摘要、Firebase 设备令牌、订阅类型和最近发送状态。咨询正文、家庭固定求助文字和回复正文不会写入通知订阅表，也不会进入锁屏载荷。

关闭通知会停用当前安装的订阅；卸载应用后设备令牌通常会失效。清除应用数据会生成新的安装标识，原有家庭守护和咨询身份仍按各自换机规则处理。

## 验收步骤

1. 在两部安卓手机安装同一 V0.8.0 体验包，并在“消息通知”中主动开启权限。
2. 按 V0.6.0 说明绑定家庭守护圈。长辈发送求助，家人手机锁屏收到概括提醒；点击后进入守护圈。
3. 用户提交脱敏人工咨询，志愿者工作台接单并回复。用户手机收到提醒；点击后进入对应工单。
4. 用户补充脱敏文字，志愿者设备收到工作台提醒；点击后进入工作台。
5. 分别验证暂停 8 小时、关闭通知、系统权限关闭、断网恢复和重复点击不会重复产生业务记录。

测试只使用虚构信息。验收时记录手机型号、Android 版本、是否锁屏、通知到达耗时和点击后的页面，不记录真实案件内容。
