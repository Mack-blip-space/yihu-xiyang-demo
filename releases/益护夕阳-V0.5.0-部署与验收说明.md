## AI 云端升级

当前新版客户端只接受 knowledgeVersion 为 2026-10-15 的云端响应。Cloudflare 需要单独更新代码：

1. 打开 Cloudflare → Workers & Pages → yihu-ai-consult → Edit code。
2. 用项目 cloud/cloudflare/worker-bundle.mjs 的全部内容替换编辑器中的 worker.js。
3. 点击 Deploy。DB、Secret、来源等现有配置不变，不要把 API Key 写入代码。
4. 打开 Worker 的 /health，确认 version 为 0.5.0，knowledgeRecords 为 22。
5. 回到 App 的问法页，用原内测邀请码重新提问。应能看到回答和“本次检索参考”。

旧版接口的三条真实测试全部成功返回，但两条出现资料未支持的具体结论。新版新增审核资料检索和有限的回答校验，仍需部署后复测。详见项目根目录 AI实测记录-V0.5.0.md。

更新：Cloudflare 现已部署完成，无需手工替换代码，也无需重装 V0.5.0 APK。当前邀请码的当天10次额度被本轮测试用满，数据库额度未修改；次日自动恢复。
