# 益护夕阳 V0.7.0：人工咨询工单

本版完成“用户提交 → 志愿者接单 → 志愿者回复 → 用户补充或确认结束”的团队内测闭环。

## 入口

- 用户端：App“智能问法”底部，或“我的 → 人工咨询工单”。
- 志愿者工作台：`https://mack-blip-space.github.io/yihu-xiyang-demo/#volunteer`
- 志愿者凭证只保存在负责人电脑的 `.private/volunteer-workbench/志愿者工作台凭证.txt`，未写入 App、GitHub 或文档正文。

## 用户体验步骤

1. 选择问题类型，填写10—1200字的虚构或脱敏问题。
2. 输入原有项目内测邀请码并同意同步说明。
3. 提交后获得 `YH-日期-随机码` 格式的咨询编号。
4. 在原设备查看“待接单、处理中、已回复、已结束”状态。
5. 可以补充脱敏文字；收到回复后可确认结束。

AI 回答下方新增“整理后申请人工咨询”。点击后只把当前问题复制到人工咨询表单，用户仍需检查内容、选择分类、再次确认并主动提交；AI 回答不会自动发送给志愿者。

## 志愿者体验步骤

1. 打开工作台地址，输入志愿者工作台凭证。凭证只在当前页面内存中保存，刷新或关闭后需重输。
2. 查看待接单、处理中、已回复数量和工单正文。
3. 接单后才能回复。并发接单时只有一位志愿者成功。
4. 回复应提供一般信息、需要核实的事实和下一步建议，不作胜诉、受理或结果承诺。
5. 用户补充后，工单回到“处理中”；回复后回到“已回复”。接单志愿者或用户可按规则结束。

## 数据和服务边界

- 这是团队内测，不是律师服务，不代表律所、检察机关、社区或其他机构已经受理。
- 不承诺即时回复。紧急危险请拨打110；普通公共法律咨询可拨打12348。
- 只收脱敏文字、问题分类、随机设备身份、状态和时间。不收姓名、电话、住址、邮箱、证件号、银行卡号或附件。
- 数据经项目 Cloudflare 服务处理，可能在境外存储。工作台有权读取用户主动提交的工单正文。
- 每台设备24小时最多提交5条，全项目最多200条；每条工单最多8次用户补充，消息列表最多返回20条。
- 工单身份保存在提交设备。清除数据或换机后不能自动恢复，咨询编号不能代替身份登录。
- 工作台凭证与用户内测邀请码分开，可单独撤销。两类凭证均不能公开。
- 人工咨询不调用模型，不消耗 AI 每日额度。

## 验证范围

自动测试覆盖完整状态流转、设备隔离、志愿者鉴权、并发接单、重复提交幂等、敏感信息拦截、每日限额、结束后不可追加及 HTTP 来源校验。发布前还需使用两个独立浏览器身份连接真实 Cloudflare/D1，走完一条测试工单并清理。
