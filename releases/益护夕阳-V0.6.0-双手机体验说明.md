# 益护夕阳 V0.6.0：家庭守护圈

本版完成一位长辈与一位家人的跨手机闭环。法学院已审核内容继续保留，无需补交资料。

## 下载与入口

- [安卓 V0.6.0 安装包](https://mack-blip-space.github.io/yihu-xiyang-demo/downloads/yihu-xiyang-v0.6.0.apk)
- [网页版守护圈](https://mack-blip-space.github.io/yihu-xiyang-demo/#family)
- App：首页 → 多方守护 → 进入家庭守护圈。紧急求助页也有入口。

## 两部手机体验

1. 两部手机安装新版，或各自打开网页版。网页与安卓 App 是不同的本机身份，不会自动互认。
2. 长辈手机选择“我是长辈”，填写原有**项目内测邀请码**，阅读并勾选同步说明，创建守护圈。此处不要填写模型 API Key。
3. 点击“生成新的家庭邀请口令”，复制给信任的家人。口令 15 分钟有效，只能绑定一部家人手机；重新生成后旧口令失效。
4. 家人手机选择“我是家人”，粘贴**家庭邀请口令**，阅读同步说明后确认加入。家人不需要项目内测邀请码。
5. 长辈刷新状态，点击“发送求助，请家人联系我”。看到保存成功后，家人打开守护圈或点击刷新，即可查看消息。
6. 家人实际电话联系或当面沟通后，点击“我已联系长辈，确认处理”。长辈刷新后能看到确认时间。
7. 任意一方可解除绑定。共享求助记录与未使用邀请会删除或失效，对方不能继续访问。长辈可重新生成口令邀请家人。

## 必须了解的边界

- 需联网；守护圈页面在前台时约每 15 秒检查状态，也可手动刷新。**尚无锁屏、退出 App 后的后台推送**，不是紧急救援送达渠道。
- “求助已保存”不代表家人已读；“家人已确认联系”由家人主动点击，不表示 App 核实了通话或实际问题已解决。
- 保留电话求助入口。网络失败或等待未确认时，页面提示刷新核对，急事应直接打电话。
- 仅同步随机设备身份、绑定关系、求助及确认时间。消息是固定文案，不上传电话、姓名、定位、案件材料或附件。云端由 Cloudflare 处理，可能在境外存储。
- 本机身份需要妥善保留。清除应用/浏览器数据或换机不支持自动找回；由仍能进入的另一方先解除绑定，再重新绑定。双方都丢失本机身份时需负责人协助排查。
- 为控制内测资源，最多 100 个长辈守护圈，同一守护圈 24 小时内最多 20 次新求助；同一时间最多一条待确认求助。重复发送不会堆积多条待处理消息。
- 家庭功能不调用模型，不占用 AI 提问次数。AI 个人每日 20 次、项目每日 100 次的配置保持不变。
- 案件记录、联系人、匿名分享等其他本机功能仍未变成跨设备共享。没有机构受理、远程代操作或志愿者接单。

## 验证与维护

自动化校验共 28 项，包括新增 7 项守护圈测试：双端流程、身份隔离、越权阻止、邀请过期/轮换/并发加入、重复求助、撤销访问、24 小时上限和请求校验。

已使用两个独立 Chrome 浏览器上下文、390px 手机视口，连接真实 Cloudflare/D1 后端完成绑定、求助、确认、刷新后身份保留、解除绑定；验证断网提示以及 320/390/768/1440px 无横向溢出。此验证不替代两部实体安卓手机的安装覆盖、真实网络及拨号体验验收。

部署源码：`cloud/cloudflare/family.mjs`；增量数据库：`family-schema.sql`。`python scripts/build_worker.py` 生成无依赖上传包，`npm run check` 执行检查。发布前保留 Worker 的现有 Secret 和 DB 绑定。回退前端不会删除服务器绑定；需要停止使用的家庭应先解除绑定。
