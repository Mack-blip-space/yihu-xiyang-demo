# 益护夕阳 V0.9.0 比赛演示版

本项目用于比赛展示，不安排真实老人、家属或志愿者试运行。测试使用自动生成的独立身份和虚构内容；自动测试不能替代真实老人可用性研究，答辩时不要声称已完成真实用户试点。

## 本版变化

- “我的 → 使用反馈”：复用工单流程，反馈标记为“使用反馈”，团队可接单、回复，原设备可查看状态。
- “我的 → 数据管理”：说明本机和云端数据范围，集中提供家庭解绑、通知管理、记录管理入口。经确认后可删除当前设备提交的全部云端咨询、反馈、回复和对应咨询通知订阅。
- “我的 → 演示检查”：查看网络和后端版本；进入团队工作台后可查看当日 AI 请求总量及通知失败订阅数。检查本身不调用模型。
- 断网、超时和异常响应使用中文提示；失败后不立即反复刷新。重复点击提交设有忙碌保护。
- Cloudflare 后台发送通知，不让推送等待阻塞已完成的业务提交。

## 五分钟演示顺序

1. 首页展示大字体、12315 / 12348 电话入口和五个模块。
2. 反诈课堂打开一篇审核内容，展示漫画和口语化说明。
3. 问答式梳理问题，保存一条虚构维权记录，说明附件仅存本机。
4. 问法输入虚构问题，展示资料引用；用已有工作台演示咨询接单、回复与状态变化。
5. “我的 → 使用反馈”提交一条界面建议，团队工作台回复，再在原设备查看。
6. 展示家庭绑定、通知设置和数据管理，最后检查服务状态。

比赛现场网络可能不稳定，提前安装 APK 并准备关键页面录屏。线下内容浏览与本机记录可演示；联网咨询、家庭同步和通知不能伪装成离线已完成。

## 已执行的验证

- 43 项 Node 自动测试通过，涵盖原 AI、资料检索、家庭绑定、咨询、推送与新增反馈/删除/用量权限。
- 浏览器模拟验证反馈预选、删除确认、服务检查不调用 AI、离线提示、请求失败恢复及 375 / 768 / 1440 像素布局；原人工咨询和通知界面测试通过。
- 真实 Cloudflare / D1 上以独立虚构身份完成反馈提交、另一设备隔离、团队接单回复、用户查看、汇总检查、删除与工作台清理。测试数据已删除。
- 本轮没有招募实际用户，也没有新增真机锁屏推送实测；此前 V0.8.0 真机体验由负责人报告完成。

## 比赛前维护与恢复

1. 在“演示检查”确认后端连通，再用一条虚构问题验证 AI。AI 总限额仍为项目每日100次、每人每日20次，失败的模型尝试也可能占用次数。
2. 保存当前 APK 和 GitHub 提交编号。发现前端问题时可使用留存 APK；回退 Worker 前要确认旧版支持当前客户端接口。
3. D1 需要备份时，在 Cloudflare 的 `yihu-ai-usage` 数据库控制台使用导出功能，文件仅放 `.private/backups/`。恢复前导入新的测试数据库验证，不覆盖现有演示环境。本轮未导出用户数据，也未执行恢复。
4. 不向公开仓库上传服务端密钥、邀请码、工作台凭证、数据库导出或原始项目书。
5. 演示结束后，在原设备的数据管理页删除虚构工单；家庭圈单独解除绑定。不要直接清除整个 App 存储，否则会丢失查找旧云端记录的设备身份。
